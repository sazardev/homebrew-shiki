# homebrew-shiki

Homebrew tap for [shiki](https://github.com/sazardev/shiki), a TUI note-taking app with a
Yazi-inspired three-pane layout and git-backed notebooks.

## Install

```sh
brew tap sazardev/shiki
brew install shiki
```

The formula in `Formula/shiki.rb` is updated automatically by shiki's own release workflow
on every tagged release — see `.github/workflows/release.yml` in the main repo.
